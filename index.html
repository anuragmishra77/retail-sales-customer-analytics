Retail Sales &

Turning transaction-level retail data into reliable business metrics using PostgreSQL, SQL and Power BI.

View source on GitHub ↗

Project objectives

Sales performance

Revenue trends, order value, product contribution and country comparisons.

Customer analytics

Repeat purchasing, RFM segmentation, cohorts and retention.

Data quality

Transparent handling of returns, cancellations, duplicates and missing identifiers.

Technology

PostgreSQLSQLPython · PandasPower BIGitHub

Analytical integrity

Revenue is not profit. The source dataset does not provide product costs, so this project will not claim actual profitability. Business findings will be added only after running and validating queries against the actual source data.

Dataset: UCI Online Retail.

Project status

Initial code scaffold and dashboard plan. Data validation, SQL execution, dashboard authoring and evidence-based findings remain to be completed.
